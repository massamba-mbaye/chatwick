# Chatwick

Add an AI chatbot (OpenAI & Claude) to any WordPress site, powered by the **Chatwick Cloud** service with prepaid credits, so there is **no AI API key to manage** on your site.

- Floating chat bubble or inline `[waicb_chatbot]` shortcode
- Answers from your own site content (knowledge base / RAG)
- Conversation history, admin dashboard, API logs
- No Composer dependencies, native PHP + WordPress Core

## Installation

**Recommended:** install from the official WordPress Plugin Directory.

👉 **https://wordpress.org/plugins/chatwick/**

In your WordPress admin, go to **Plugins → Add New**, search for **Chatwick**, then **Install → Activate**. Updates are delivered automatically.

**Manual:** download `chatwick-1.7.0.zip` from the [latest release](../../releases/latest), then in WordPress: **Plugins → Add New → Upload Plugin → Activate**.

After activation, open **Chatwick → Settings**, connect your Chatwick account and enable the widget.
